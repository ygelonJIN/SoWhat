# So What（爱·对·赢 Love · Right · Win）

一个围绕「打开即聊天框 + 三视角分析 + 长期记忆」构建的情侣对话复盘原型。应用显示名称为 **So What**，三个模式（对外统一文案）：**为爱** / **论对错** / **比输赢**。

## 当前状态（v0.17）

- **打开即聊天框**：文字输入 + 截图上传（相册多选、压缩进私有目录、顶部扇面暂存、点「发送」才写入对话并触发分析）
- **三模式分析**：为爱 / 论对错 / 比输赢，逐维度分析卡片 + 可折叠思考面板（按「对话+视角」持久化）；多对话 × 多模式可并行分析，切换视角不取消
- **长期记忆**：记忆档案页（入口 = 输入框上方「记忆」）——九板块档案 + 四份概况 + 手动「更新记忆」（已接入真实 AI：cardRef 出处、动态「仍在/变化」对比 + 静态去重、截断自动精简重试）
- **BYOK**：设置页「配置 API」填小米 MiMo 接口（OpenAI / Anthropic 双协议、测试连接、API Key 进 Keychain/Keystore）；**未配置时分析/记忆生成抛错引导去配置，不回退演示**
- **数据本地优先**：Drift SQLite + 私有 `assets` 目录，无账号、无服务器
- **设置页**（左上「设置」展开左侧 3/4 面板）：搜索记录、配置 API、新建对话、聊天记录（置顶 / 重命名 / 分享 `.sowhat.zip` / 删除，删除可勾选连同记忆）；底部资产管理（分组预览 + 搜索 + 空间统计 + 再压缩）、导入聊天记录、清空数据

## 运行

使用工作区统一的 Flutter 入口：

```bash
./tool/flutter run
```

环境：Flutter 3.47.0（本机 `~/fvm/versions/3.47.0`），详见产品文档 §8.4。
注意：需要写 SDK cache 的 flutter 命令（`run` / `build` / `pub get` / `clean` 等）请在**你自己的终端**执行——编辑器内嵌终端受 macOS 沙箱限制无法写入主目录 SDK 缓存。

## 说明

- 三个模式对外文案统一为「为爱 / 论对错 / 比输赢」（历史别名「争爱 / 争对错 / 争输赢」仅在代码注释保留）。
- 战场图形视觉与每轮 headline 渲染**明确不做**；模式战况总结块（模型 JSON 结尾的 `headline`）在分析卡片流顶部展示。
