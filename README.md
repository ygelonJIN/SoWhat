# So What（Love · Right · Win）

一个围绕「打开即聊天框 + 三视角分析 + 长期记忆」构建的情侣对话复盘原型。

应用显示名称为 **So What**；三个模式仍保留产品语义：为爱 / 论对错 / 比输赢。

## 当前状态

- 主界面已切换为聊天框形态
- 支持文字输入与截图导入（`image_picker`）
- 支持三种分析视角：争爱 / 争对错 / 争输赢
- 已接入长期记忆的占位档案结构
- 已接入 V1 导出分析包通道，可复制到免费 AI 进行分析

## 运行

使用工作区统一的 Flutter 入口：

```bash
./tool/flutter run
```

## 说明

当前仍然是原型阶段，真实 AI 接口、长期记忆管理页和本地数据库后续再接入。
